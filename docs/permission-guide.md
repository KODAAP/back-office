Voici les permissions, extraites du document actuel ("Koda\_review\_20260216"), pour les rôles d'Admin, Project Manager et Utilisateur simple :

### **Permissions de l'Utilisateur simple**

Les utilisateurs ont deux types : ceux avec une adresse e-mail Insuco (connexion via SSO) et les utilisateurs externes (invités par les Admins).

Les droits de l'Utilisateur sont :

  * Accès aux projets auxquels il a été invité (accès donné par l'Admin ou le Project Manager).
  * Accès limité au projet, leur permettant de :
      * Télécharger l'XLSForm du formulaire.
      * Accéder au tableau de bord de l'enquête (*Survey dashboard*).
      * Revoir les données.
      * Télécharger les données.
      * Accéder aux codes QR.
      * Accéder aux questionnaires web.
      * Envoyer des soumissions.
  * Ils peuvent devenir Project Manager si l'Admin leur donne ce privilège.

### **Permissions du Project Manager**

Le Project Manager est un utilisateur avec des droits plus élevés sur les projets. Ils possèdent les droits de l'Utilisateur sur leur projet, plus les suivants :

  * Ils peuvent inviter d'autres Utilisateurs dans le projet et les nommer Project Manager.
  * Ils peuvent créer, modifier et supprimer des enquêtes (*surveys*).
  * Ils peuvent créer, modifier et supprimer les accès des enquêteurs (*surveyors*) via des codes QR.
  * Ils peuvent créer, modifier et supprimer les accès des utilisateurs web.

### **Permissions de l'Admin**

L'Admin est un utilisateur avec des droits d'administrateur, généralement un analyste de données. Ils ont les droits suivants :

  * Ils peuvent créer des projets.
  * Ils ont le rôle de Project Manager sur chaque projet.
  * Ils ont accès à la page **Users** (Utilisateurs), qui présente la liste des utilisateurs et leurs projets affiliés.
  * Ils gèrent les Utilisateurs, notamment en :
      * Invitant des utilisateurs externes (avec leur adresse e-mail).
      * Accordant/révoquant leur accès aux projets.
      * Nommant le Project Manager, projet par projet.
  * Ils gèrent spécifiquement les projets des utilisateurs supprimés : en cas de révocation de l'e-mail Insuco ou de suppression de l'utilisateur externe, les Admins reçoivent une notification pour gérer les projets de l'utilisateur concerné.
  * Seul un Administrateur peut supprimer un projet (le Project Manager peut uniquement l'archiver).
